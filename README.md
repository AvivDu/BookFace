# BookFace Project

## Introduction
This project is a C++ application named **BookFace**. It includes several components such as `System`, `FriendClass`, and `Gamemenu`.

## Prerequisites
- Windows operating system
- Visual Studio installed
- C++14 compatible compiler

## Running the Project

1. **Clone the project**:
   ```bash
   git clone https://github.com/AvivDu/BookFace.git
   ```

2. **Open the project in Visual Studio**:
   - Open Visual Studio.
   - Go to `File -> Open -> Project/Solution`.
   - Navigate to the cloned repository and open the solution file.

3. **Build the project**:
   - In Visual Studio, go to `Build -> Build Solution`.

4. **Run the project**:
   - Set `main.cpp` as the startup file.
   - Press `F5` to run the project.

## Project Structure
- `main.cpp`: Entry point of the application.
- `system.h` and `system.cpp`: Contains the `System` class implementation.
- `FriendClass.h`: Contains the `FriendClass` class definition.
- `gamemenu.h`: Contains the `Gamemenu` class definition.

## Usage
- The application starts by creating an instance of the `Gamemenu` class.
- The `Gamemenu` class handles the user interactions and navigations within the application.

## Terminate the Project
- To stop the application, simply close the console window or stop the debugging session in Visual Studio.

## Notes
- Ensure that all dependencies are correctly included and linked in the Visual Studio project settings.
- If you encounter any issues, check the output pane in Visual Studio for error messages and resolve them accordingly.
